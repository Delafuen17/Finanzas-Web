# Proyecto Finanzas

Web de educación financiera: aprende a entender tu dinero y la bolsa desde cero.

Publicada con GitHub Pages.

## Cómo trabajar en local

1. Edita los archivos en tu ordenador.
2. Prueba abriendo `index.html` en el navegador.
3. Guarda los cambios en Git:

```bash
git add .
git commit -m "descripción del cambio"
git push
```

GitHub Pages publica automáticamente la versión de la rama `main`.
